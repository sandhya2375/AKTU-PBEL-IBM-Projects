# AKTU PBEL – IBM AI & Machine Learning Projects

## Overview

This repository contains five projects completed as part of the **AKTU Project-Based Experiential Learning (PBEL)** program in collaboration with **IBM**.

Each project is organized in a separate folder and includes the project files and presentation (PPT) submitted as part of the program.

---

## Projects

### Project 1: Salary Prediction using Ensemble Learning
Builds a machine learning model to predict salary using ensemble learning techniques.

### Project 2: Text Analytics for Spam Detection using Naive Bayes
Implements a spam detection system using Natural Language Processing (NLP) and the Naive Bayes algorithm.

### Project 3: Image Classification using CNN
Develops a Convolutional Neural Network (CNN) model for image classification (Cats vs Dogs / Fruits).

### Project 4: Book Recommendation Chatbot using IBM Watson Assistant
Creates a chatbot using IBM Watson Assistant to recommend books based on user interactions.

### Project 5: AutoAI Model Building in IBM Watson Studio
Demonstrates automated machine learning model creation using IBM Watson Studio AutoAI.
